CyberQuiz 🛡️

An interactive Cyber Security Quiz Web Application developed for university examination purposes.
This project helps users test their knowledge of cybersecurity, cyber law, IT Act, malware, cryptography, networking, and digital forensics through a modern quiz interface.

🌐 Live Demo:
🔗 https://cybersecurityquizz.netlify.app/

🚀 Features
🎯 Multiple cybersecurity topics
📊 Real-time score tracking
🏆 Leaderboard system using Local Storage
⏱ Quiz timer
📈 Topic-wise performance breakdown
🎨 Modern cyberpunk-inspired UI
📱 Responsive design for mobile & desktop
🔄 Randomized questions
✅ Instant answer feedback
🛠️ Technologies Used
HTML5
CSS3
JavaScript
Local Storage API
Netlify (Deployment)
